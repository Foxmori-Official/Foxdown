# Foxdown 界面复核

2026-11-11。范围为桌面应用与 Chrome／Edge 扩展。沿用 Foxmori 的暖白、森林绿、柔和边框和狐形标识。

## 评价与调整

按照 Impeccable 的 Operate 场景检查任务操作、信息层级、设置分组和错误恢复；结合 Design Taste Frontend 检查品牌一致性、对齐、字体、色彩和实际渲染。功能修复与引擎测试独立完成。

| 界面 | 原有问题 | 当前设计 |
|---|---|---|
| 任务列表 | 空状态重复出现新建入口，快速完成的任务不易找到 | 保留工具栏主操作，默认显示「全部」，弱化空闲统计区域 |
| 设置 | 长表单、窄窗口和内外滚动叠加，保存状态不明确 | 七组分类切换，每次只显示一组；低频选项折叠，统一显示保存中、保存失败与重试 |
| 连接失败 | 无法判断是否令牌错误或服务未启动 | 区分连接状态，保留输入，给出对应恢复入口 |
| 扩展引导 | 未连接也能进入后续步骤 | 验证真实地址与令牌后继续，演示使用已验证的服务 |
| 扩展选项 | 高级规则与基本设置层级接近 | 基本设置优先，路由放入高级区域，保存状态保持可见 |
| 深色主题 | 次要计数和状态可能对比不足 | 为计数、文字和状态设置成对的前景与背景色 |

复核结果：任务操作与系统状态容易区分，设置有明确分组，扩展与桌面应用使用同一视觉语言。保留 BT、RPC、HLS 等专业术语，在相应区域提供说明，适合需要浏览器接管和多种下载方式的桌面用户。

## 验证范围

- 真实打包应用中的任务、设置、令牌恢复，以及 Chromium 扩展的连接、接管、保存同步和失败回退。
- 桌面 760、1024、1440 像素窗口与浅色、深色主题的实际渲染。扩展引导和弹出面板另行检查。
- 默认窗口上限增至 1360×900，按屏幕可用区域调整；普通屏幕最小窗口为 1080×760。设置页取消内部滚动容器，并逐组检查横向溢出。在内容高度不低于 800 像素时，常用设置完整显示。
- Impeccable 扫描覆盖的页面未报告规则问题。机械扫描作为补充，不能代替实际界面检查。
- 产品界面采用任务操作布局。营销页的首屏宣传区、摄影、滚动效果及手机端规则不作为此次调整目标。

平台构建与功能验证记录见 [verification.md](verification.md)。
