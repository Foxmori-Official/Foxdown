Foxdown v0.0.4 调整桌面端设置和侧栏导航，让常用选项与浏览器扩展安装指南更容易找到。

- 设置分类在侧栏常驻展开，任务页面也可直接进入任一分类。点击「设置」可回到上次查看的分类。
- 将「登录时打开 Foxdown」和「当前版本／检查更新」合并到「基本」，按「断点续传 → 登录时打开 Foxdown → 当前版本／检查更新 → 进阶设置」排列。
- 将「浏览器扩展安装指南」放到侧栏，与「任务」「设置」同级。点击后在默认浏览器中打开安装指南。

### 下载与安装

| 系统与芯片 | 文件 |
| --- | --- |
| macOS 13 及以上，Apple 芯片 | `Foxdown-0.0.4-mac-arm64.dmg` |
| macOS 13 及以上，Intel 芯片 | `Foxdown-0.0.4-mac-x64.dmg` |
| Windows，Intel／AMD | `Foxdown-0.0.4-win-x64.exe` |
| Windows 11 on Arm | `Foxdown-0.0.4-win-arm64.exe` |
| Chrome／Edge 扩展 | `Foxdown-extension.zip` |

更新扩展时，解压 ZIP 并替换扩展目录，再从浏览器的扩展管理页重新加载。`SHA256SUMS.txt` 包含上述五个文件的校验值。

### 已知限制

流媒体清单引用跨域资源时，下载请求可能携带原站的 Cookie 和 Authorization。下载需要登录的流媒体时，请确认清单及其引用资源的来源可信。

macOS 应用使用临时签名，尚未公证。Windows 安装程序尚未配置发布者签名。
