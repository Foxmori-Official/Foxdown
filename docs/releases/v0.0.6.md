Foxdown v0.0.6 将网页视频解析扩展到 yt-dlp 支持的站点，并把播放时发现的资源和主动解析结果汇入同一列表。

- 在扩展中点击「解析页面视频」，即可调用已安装的 yt-dlp 查找完整的视频直链与 HLS／DASH 清单。[yt-dlp 安装方式](https://github.com/Foxmori-Official/Foxdown/blob/v0.0.6/docs/electron.md#可选的-yt-dlp-解析器)
- 本页资源按发现顺序排列，新结果追加在末尾。同一地址只显示一行，解析结果可补充清晰度和大小。
- 资源列表过滤 HLS 播放中的 `.ts` 分片，保留清单及作为独立文件下载的 `.ts`。

### 下载与安装

| 系统与芯片 | 文件 |
| --- | --- |
| macOS 13 及以上，Apple 芯片 | `Foxdown-0.0.6-mac-arm64.dmg` |
| macOS 13 及以上，Intel 芯片 | `Foxdown-0.0.6-mac-x64.dmg` |
| Windows，Intel／AMD | `Foxdown-0.0.6-win-x64.exe` |
| Windows 11 on Arm | `Foxdown-0.0.6-win-arm64.exe` |
| Chrome／Edge 扩展 | `Foxdown-extension.zip` |

建议同时更新桌面版和扩展。手动更新扩展时，解压 ZIP 并替换原目录，在浏览器的扩展管理页重新加载，然后刷新要使用的网页。`SHA256SUMS.txt` 提供上述五个文件的 SHA-256 校验值。

### 已知限制

网页解析结果取决于 yt-dlp 版本及站点当前提供的媒体格式。Foxdown 可下载完整直链以及含音视频的 HLS／DASH 清单。

流媒体清单引用跨域资源时，下载请求可能携带原站的 Cookie 和 Authorization。下载需要登录的流媒体时，请确认清单及其引用资源的来源可信。

macOS 应用使用临时签名，尚未公证。Windows 安装程序尚未配置发布者签名。
