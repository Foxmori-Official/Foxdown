Foxdown v0.0.3 更新 macOS 和 Windows 安装体验，并为桌面应用和浏览器扩展加入版本显示与更新检查。

- macOS 安装窗口采用 Foxdown 的品牌配色。将左侧 Foxdown 图标沿箭头拖到右侧「应用程序」即可安装。
- Windows 安装程序在同一页提供安装语言、安装目录和桌面快捷方式。支持简体中文和英语。首次安装默认勾选桌面快捷方式，可手动取消。覆盖安装时根据已有快捷方式预填。点击「安装」后开始复制文件。
- 桌面应用在左侧栏及「设置 → 应用」显示版本号，浏览器扩展在弹出面板及选项页显示版本号。桌面应用和扩展都可手动检查 GitHub 上的最新正式版本，并在有更新时提供下载入口。

### 下载与安装

| 系统与芯片 | 文件 |
| --- | --- |
| macOS 13 及以上，Apple 芯片 | `Foxdown-0.0.3-mac-arm64.dmg` |
| macOS 13 及以上，Intel 芯片 | `Foxdown-0.0.3-mac-x64.dmg` |
| Windows，Intel／AMD | `Foxdown-0.0.3-win-x64.exe` |
| Windows 11 on Arm | `Foxdown-0.0.3-win-arm64.exe` |
| Chrome／Edge 扩展 | `Foxdown-extension.zip` |

更新扩展时，解压 ZIP 并替换扩展目录，再从浏览器的扩展管理页重新加载。`SHA256SUMS.txt` 包含上述五个文件的校验值。

macOS 应用使用临时签名，尚未公证。Windows 安装程序尚未配置发布者签名。
