Foxdown v0.0.5 内置 yt-dlp，将网页视频解析与浏览器自动嗅探的结果汇入同一个资源列表。

- 在扩展中点击「解析页面视频」，即可使用内置 yt-dlp 查找支持站点的完整视频直链与 HLS／DASH 清单，无需另装解析器。[网页视频解析说明](https://github.com/Foxmori-Official/Foxdown/blob/v0.0.5/docs/electron.md#内置的-yt-dlp-解析器)
- 资源按发现顺序排列，相同地址合并为一行。新资源追加时保留选中的文字和按钮焦点。列表过滤 HLS 播放分片，保留清单和独立文件，长文件名可完整显示。
- 下载带独立音轨的 HLS 视频时，默认将视频和音频合并到同一个文件。关闭合并时会分别保存两条轨道。
- 成功接管后，扩展会等待 Chrome 取消原下载并清理该记录，遇到短暂失败会重试。转交失败时恢复浏览器下载。

此前下载过 v0.0.5 或 v0.0.6 的用户，请重新下载本页的桌面安装包和扩展。手动更新扩展时，解压 ZIP 并替换原目录，在浏览器的扩展管理页重新加载，然后刷新要使用的网页。`SHA256SUMS.txt` 提供上述五个文件的 SHA-256 校验值。

### 已知限制

网页解析结果取决于站点当前提供的媒体格式。Chrome 在启动下载和转交期间可能短暂显示原生下载图标。

流媒体清单引用跨域资源时，下载请求可能携带原站的 Cookie 和 Authorization。下载需要登录的流媒体时，请确认清单及其引用资源的来源可信。

macOS 应用使用临时签名，尚未公证。Windows 安装程序尚未配置发布者签名。
