Foxdown v0.0.5 改进网页资源发现，支持查找 X 公开帖子中的完整视频，并修复 HLS 下载丢失独立音轨的问题。

- 打开 X 的单条帖子，在扩展中点击「查找此帖视频」。Foxdown 优先使用桌面端已安装的 yt-dlp，无法解析时会尝试 X 的公开嵌入接口。资源列表会归并同一视频的地址，并过滤初始化片段和独立的流媒体分片。[yt-dlp 安装方式](https://github.com/Foxmori-Official/Foxdown/blob/v0.0.5/docs/electron.md#可选的-yt-dlp-解析器)
- 新发现的资源追加到列表末尾，保留当前选中的文字、按钮焦点和转交状态。长文件名会完整换行显示。
- 下载带独立音轨的 HLS 视频时，默认将视频和音频合并到同一个文件。关闭合并时会分别保存两条轨道。
- 成功接管后，扩展会等待 Chrome 取消原下载并清理该记录，遇到短暂失败会重试。转交失败时恢复浏览器下载。

### 下载与安装

| 系统与芯片 | 文件 |
| --- | --- |
| macOS 13 及以上，Apple 芯片 | `Foxdown-0.0.5-mac-arm64.dmg` |
| macOS 13 及以上，Intel 芯片 | `Foxdown-0.0.5-mac-x64.dmg` |
| Windows，Intel／AMD | `Foxdown-0.0.5-win-x64.exe` |
| Windows 11 on Arm | `Foxdown-0.0.5-win-arm64.exe` |
| Chrome／Edge 扩展 | `Foxdown-extension.zip` |

建议同时更新桌面版和扩展。手动更新扩展时，解压 ZIP 并替换原目录，在浏览器的扩展管理页重新加载，然后刷新要使用的网页。`SHA256SUMS.txt` 提供上述五个文件的 SHA-256 校验值。

### 已知限制

X 帖子查询使用公开接口，取决于帖子是否公开以及站点当前返回的媒体格式。Chrome 在启动下载和转交期间可能短暂显示原生下载图标。

流媒体清单引用跨域资源时，下载请求可能携带原站的 Cookie 和 Authorization。下载需要登录的流媒体时，请确认清单及其引用资源的来源可信。

macOS 应用使用临时签名，尚未公证。Windows 安装程序尚未配置发布者签名。
