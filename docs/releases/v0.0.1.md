## 简体中文

Foxdown v0.0.1 是首个构建版本，提供 macOS、Windows 桌面应用和 Chrome／Edge 浏览器扩展。

### 本版内容

- 支持 HTTP、BT／磁力链接和 HLS／DASH 流媒体下载。
- 安装包内置 aria2、FFmpeg 和 FFprobe，首次启动无需下载引擎。
- 采用左右布局，左侧「设置」可展开七个分类，右侧显示对应内容。
- 支持自动保存、批量任务失败反馈、连接恢复和下载失败重试。
- 扩展提供连接引导、令牌验证、网页媒体发现和下载接管；服务不可达时恢复浏览器下载。
- 提供参考项目更新报告和版本维护流程。

### 下载与安装

| 系统与芯片 | 文件 |
|---|---|
| macOS 13 及以上，Apple 芯片 | `Foxdown-0.0.1-mac-arm64.dmg` |
| macOS 13 及以上，Intel 芯片 | `Foxdown-0.0.1-mac-x64.dmg` |
| Windows，Intel／AMD | `Foxdown-0.0.1-win-x64.exe` |
| Windows 11 on Arm | `Foxdown-0.0.1-win-arm64.exe` |
| Chrome／Edge 扩展 | `Foxdown-extension.zip` |

先安装并启动桌面版，再解压扩展 ZIP，在浏览器扩展页面开启开发者模式并加载解压后的目录。默认连接地址为 `http://127.0.0.1:16801`。

`SHA256SUMS.txt` 包含以上五个文件的校验值。

### 构建与验证

安装包与扩展由 GitHub Actions 构建。macOS ARM64 安装包在 Intel Mac 执行器上交叉打包，并校验可执行组件的 ARM64 架构与应用签名。原生 ARM64 启动和浏览器扩展联动另在 Apple 芯片开发机验证，具体范围见 [验证记录](https://github.com/Foxmori-Official/Foxdown/blob/v0.0.1/docs/verification.md)。

### 已知限制

- macOS 应用采用临时签名，尚未完成 Apple 公证；Windows 安装包尚未配置发布者签名。
- Windows ARM64 桌面进程为原生 ARM64，下载引擎通过 Windows 11 的 x64 模拟层运行。
- 浏览器扩展目前通过加载已解压目录安装。

## English

Foxdown v0.0.1 is the first build, with desktop apps for macOS and Windows and a Chrome/Edge extension.

### Included

- HTTP, BitTorrent, magnet links, and HLS/DASH downloads.
- Bundled aria2, FFmpeg, and FFprobe, with no engine download required at first launch.
- A left sidebar with seven expandable settings categories and the selected settings on the right.
- Autosave, batch failure feedback, connection recovery, and download retries.
- Extension onboarding, token verification, media discovery, download handoff, and browser fallback when the desktop service is unreachable.
- Upstream change reports and documented release maintenance.

### Installation

Choose the installer matching your OS and architecture from the file table above. Start the desktop app, extract `Foxdown-extension.zip`, then load the extracted directory in your browser's developer mode. The default service URL is `http://127.0.0.1:16801`. `SHA256SUMS.txt` lists checksums for all five downloads.

### Known limitations

- macOS builds are ad-hoc signed and not notarized. Windows builds do not have a publisher signature.
- The Windows ARM64 desktop app is native ARM64; its bundled engines use Windows 11 x64 emulation.
- The browser extension is currently installed by loading its unpacked directory.

### Build verification

GitHub Actions builds the installers and extension. The macOS ARM64 package is cross-packaged on an Intel Mac runner with ARM64 Mach-O and signature verification. Native ARM64 startup and browser integration are verified on Apple Silicon development hardware. See the [verification record](https://github.com/Foxmori-Official/Foxdown/blob/v0.0.1/docs/verification.md) for coverage.
