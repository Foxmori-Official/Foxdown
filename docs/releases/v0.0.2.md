Foxdown v0.0.2 更新桌面应用与浏览器扩展，重点修复下载正确性、安全边界和任务操作，并整理仓库内容。

### 下载与任务

- 同一文件下载到同一目录时保留已有文件，新增下载自动分配文件名；原生流媒体并发重名输出同样保留副本。
- 新增一键清空已完成任务记录，确认提示明确说明磁盘文件会保留。
- 修复 HLS 连续字节区间和初始化片段读取、DASH 签名地址与 BaseURL、有限时间轴展开及纯音频下载。
- 恢复和重试流媒体任务后立即返回，退出时等待进度保存，改善断点续传可靠性。
- 修复外部流媒体引擎的速度单位、启动失败反馈和旧进程退出干扰新任务的问题。

### 界面与扩展

- 桌面应用、组件库和扩展只提供简体中文和英语，保留自动语言选择，移除旧语言配置迁移。
- 保留默认网页资源嗅探、当前标签资源数量、进行中任务数量和失败 X 角标。
- 扩展连接仅识别 Foxdown 服务；移除旧 CLI 和旧品牌环境变量别名，使用 `FOXDOWN_*` 配置。

### 安全与维护

- 修复截断 torrent 引起的服务阻塞，限制元数据读取和 DASH 展开工作量。
- 加强设置类型与范围检查、浏览器调用权限、下载目录和符号链接边界，凭据比较采用恒定时间比较。
- 任务与分片进度采用异步原子保存，HLS 直接通过流送入 FFmpeg，减少临时文件读写。
- Windows 文件临时占用时，任务进度保存会有限重试原子替换，保留原文件，避免写入偶发失败。
- 更新 Electron、vue-i18n 和端口映射依赖，处理已知依赖告警。
- 合并历史审查文档，删除重复入口、失效 HLS 样例和被现有测试替代的工具；保留当前验证、许可与来源记录。
- Docker 使用 Node.js 22，从干净源码构建网页和图标，并固定非 root 用户 UID 为 1000。

### 下载与安装

| 系统与芯片 | 文件 |
| --- | --- |
| macOS 13 及以上，Apple 芯片 | `Foxdown-0.0.2-mac-arm64.dmg` |
| macOS 13 及以上，Intel 芯片 | `Foxdown-0.0.2-mac-x64.dmg` |
| Windows，Intel／AMD | `Foxdown-0.0.2-win-x64.exe` |
| Windows 11 on Arm | `Foxdown-0.0.2-win-arm64.exe` |
| Chrome／Edge 扩展 | `Foxdown-extension.zip` |

先启动桌面版，再从同一版本附件解压并加载浏览器扩展。默认服务地址为 `http://127.0.0.1:16801`，更新扩展后刷新已打开网页。`SHA256SUMS.txt` 提供五个下载文件的校验值。

旧 CLI 入口和 `KIMI_*`／`RDOWN_*` 环境变量别名已移除；脚本与自动化请使用 `cli/foxdown.mjs`、`FOXDOWN_*`。设置、已有文件和任务数据库继续使用现有数据目录。

### 验证与限制

本机已验证 512 MiB 文件和 Node.js 官方 106 MB 源码包的 8 连接下载、暂停恢复和 SHA-256。功能、性能、安全及平台覆盖范围见[当前验证记录](https://github.com/Foxmori-Official/Foxdown/blob/v0.0.2/docs/verification.md)，跨平台产物以本次 GitHub Actions 的构建与测试结果为准。

macOS 使用临时签名、尚未公证；Windows 未配置发布者签名。Windows ARM64 的下载引擎通过 Windows 11 x64 模拟运行。真实路由器端口映射和可选 N_m3u8DL-RE 下载未做实机验证。
