# Foxdown 图标

采用内置 imagegen 生成。源图位于 `extension/icons/icon-source.png`，`npm run assets` 生成桌面、浏览器和商店所需尺寸。

macOS 使用单独生成的 `web/public/icon-mac.png`：1024×1024、完全不透明的森林绿背景，交由系统裁切形状，避免透明边距被归一化成额外的浅色底板。扩展、网页及 Windows 继续使用适合各自尺寸的透明版本。

设计沿用 Foxmori 的森林绿、赤狐橙和奶油白。狐狸的环抱尾巴在底部形成向下的尖端，表达收集和下载。
