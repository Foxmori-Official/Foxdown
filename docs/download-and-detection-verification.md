# 下载状态与资源嗅探验证

验证日期为 2026-11-13，环境为 macOS ARM64、Node.js 22.23.5、项目内置 aria2 1.36.0 和 Playwright Chromium。

## 扩展状态反馈

工具栏角标显示下载中和等待任务的合计数量，超过 999 时显示 999+。发送期间立即反馈任务数，暂停和已完成任务退出计数。失败任务、发送失败或服务不可达时显示红色 X，鼠标悬停可查看状态摘要，扩展弹窗列出失败文件与错误原因。

重试或删除失败任务后，角标按最新状态恢复。发送失败提示可在弹窗清除。角标状态通过 WebSocket 实时更新，关闭系统通知仍继续更新，并汇总多服务器路由中的任务。重复指向同一服务的路由按同一服务计数。

空闲时，当前标签页发现的资源数量以蓝色角标显示，资源列表和鼠标悬停说明中也会显示数量。下载进行中时显示绿色任务数，失败时显示红色 X；任务结束后恢复当前页面的资源数。切换标签页显示各自资源数量，页面导航后清空旧资源。角标由 Chrome 的 action API 绘制，定位遵循浏览器的工具栏样式。接口行为见 [Chrome action 文档](https://developer.chrome.com/docs/extensions/reference/api/action#badge)。

## 资源嗅探

重新读取 cat-catch 的 manifest、background、init 和 popup 源码，对照了响应开始时的识别流程、后缀与 MIME 检测、Content-Disposition 附件文件名解析，以及按标签页缓存和展示资源的方式。上游对照提交为 019c465794b5871701383e4485c0e9ee7be2f840。 [cat-catch 资源识别源码](https://github.com/xifangczy/cat-catch/blob/019c465794b5871701383e4485c0e9ee7be2f840/js/background.js)

Foxdown 的嗅探默认值原本已为 true，原弹窗会在资源为空时隐藏整个区域。本次将“本页资源”固定显示，增加自动嗅探开关、页面标题和空状态提示，设置页左侧仪表盘也提供资源入口。用户已经关闭的开关按保存值显示。

已补充响应附件名和 UTF-8 文件名识别，支持 URL 没有媒体后缀的资源，以及服务端声明的可下载附件。资源列表显示本页缓存的全部条目，最多 200 项。网络失败响应不加入资源列表。

浏览器开始接收到资源后即可捕获。网页已经加载完成后新安装扩展时，可以播放媒体或刷新网页。深度搜索可补充页面脚本中的候选地址。

## 多连接与分段下载

测试通过 Foxdown 的正常任务 API 创建任务，运行内置 aria2，设置 split=8、maxConnectionPerServer=8、minSplitSize=1M。全局速度上限为 16 MiB/s，用于持续观察并行连接和暂停／继续行为。

| 文件 | 字节数 | 观测到的最大连接数 | 校验结果 |
|---|---:|---:|---|
| 本地 Range 服务生成的 512 MiB 文件 | 536870912 | 8 | 下载结果与源数据 SHA-256 一致 |
| Node.js 官方 v22.23.5 源码包 | 106194544 | 8 | 与官方 SHA-256 清单一致 |

512 MiB 测试记录了 19 次请求，服务端最多同时处理 8 个请求，其中包含多个从非零字节位置开始的 206 Partial Content 响应。下载到至少 32 MiB 后暂停，再恢复下载，最终内容校验通过。两次文件下载分别约 35.2 秒和 10.0 秒，时间受测试限速和当前网络影响。

外部文件的 SHA-256 为 `5ae198a2ec0513ea8b7ef28f71094c9a7931a44e4db17b1734d76fe958e0ff36`，校验依据为 [Node.js 官方清单](https://nodejs.org/dist/v22.23.5/SHASUMS256.txt)。原始连接和 Range 记录保存在本次运行的 `.scratch/download-validation/result.json`。

可用 `npm run test:desktop-multiconnection` 重新运行，测试会实际下载官方源码包并清理临时文件。设置 FOXDOWN_DOWNLOAD_REPORT 可保存 JSON 结果。
