01

浏览器下载接管

接管浏览器发起的下载，或通过链接右键菜单手动发送。按域名、文件类型与大小配置接管规则。

02

发现页面资源

默认开启媒体嗅探，查看当前标签页的资源数量，预览支持的媒体，并选择需要下载的资源。

03

管理下载任务

支持多连接、分段下载、暂停与恢复。在桌面应用中查看进度，在扩展里了解任务数量和错误状态。

开始使用

先运行桌面版，再连接扩展

浏览器扩展需要可用的 Foxdown 下载服务才能执行下载，无需注册账号。

  1. 安装 Foxdown

    从 Releases 选择适合系统和芯片的安装包，安装并启动桌面应用。

  2. 安装浏览器扩展

    按扩展安装指南加载扩展，并将它固定到浏览器工具栏。

  3. 验证连接

    默认服务地址为 http://127.0.0.1:16801。如果服务设置了 Web API Token，在扩展中填写同一个令牌，测试连接后即可使用。

数据与权限

下载信息的去向，由服务配置决定

扩展会处理页面地址、媒体链接，以及下载所需的 Cookie、Authorization 等请求头，并将下载信息交给你配置的 Foxdown 服务。默认连接本机；媒体预览会访问资源站点，手动检查更新会访问 GitHub。

无广告，不出售用户数据。接管、嗅探及自动功能可以分别设置。完整的数据用途、保存与清理范围见隐私政策。

阅读隐私政策

桌面版支持 macOS 13 及以上和 Windows。当前 macOS 安装包尚未公证，Windows 安装包尚未配置发布者签名。系统与芯片选择、安装提示见桌面端说明。
